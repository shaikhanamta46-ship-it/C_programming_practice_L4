# C Loop Practice Programs

This repository contains basic C programs demonstrating different types of loops and control statements.

##  Topics Covered

* **While Loop**

  * Printing messages multiple times
  * Printing variable values
  * Infinite loop example

* **Do-While Loop**

  * Executes at least once regardless of condition
  * User input-based loop

* **For Loop**

  * Incrementing loop
  * Decrementing loop

* **Loop Control Statements**

  * `break` → exits loop
  * `continue` → skips current iteration

* **Operators**

  * Assignment and shorthand operators (`+=`, `-=`, etc.)
  * Increment (`i++`) and decrement (`i--`)

## Practice Examples

* Print "Happy Birthday" multiple times
* Print numbers in a range (e.g., 10 to 20)
* Print natural numbers using different loops
* Demonstrate infinite loops
* Work with increment/decrement operations

## How to Run

1. Install a C compiler (like GCC)
2. Compile the program:

   ```bash
   gcc filename.c -o output
   ```
3. Run the program:

   ```bash
   ./output
   ```

##  Purpose

This project is designed for beginners to understand:

* Loop structures in C
* Control flow
* Basic programming logic
